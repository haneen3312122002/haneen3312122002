## How I build

| Principle | In practice |
|---|---|
| **Layered architecture** | Feature-first Clean Architecture, repository pattern, business logic in ViewModels, never in widgets |
| **Security by design** | Score/streak logic in Cloud Functions behind App Check, RBAC via Firestore Security Rules, AES-256 for local secrets |
| **Release automation** | Node.js pipeline to Google Play, GitHub Actions to Firebase Hosting |
| **Offline-first UX** | Local caching layer, SQLite/sqflite persistence, graceful sync |
| **Quality** | SOLID, immutable models with Freezed, DI with get_it, currently deepening unit and widget testing |
